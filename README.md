# CMCA-KGC

This repository contains the core implementation of CMCA-KGC, a knowledge graph completion framework with channel mixing and multi-scale community awareness.

The current release provides the main model architecture, community-aware representation modules, channel-mixing mechanism, probabilistic contrastive objective, configuration files, and basic training and evaluation interfaces.

The current release provides the core implementation and basic running instructions. Additional data preparation scripts, detailed training protocols, validation utilities, and experimental configurations will be progressively updated to further improve reproducibility.
